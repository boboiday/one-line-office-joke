A single-line joke about office life, written by a deterministic program for the [One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162) bounty on make.fun.

> Our office printer only works when nobody needs it, which HR calls 'work-life balance'.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Writes exactly one line (87 characters) to `/output/entry.txt`. No randomness, no clock, no network — the same line every run.
